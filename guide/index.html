Տեխնիկական տեղեկանք (ծրագրավորողի համար)

Կառուցվածք՝ մեկ ֆայլ armtrade/index.html (HTML+CSS+JS, առանց framework-ների)։ Հոսթինգ՝ Cloudflare Pages, ավտոմատ deploy GitHub-ից՝ github.com/hrachyajavadyan/assay։

Համաժամացում՝ Cloudflare Pages Function functions/api/room/[code].js + D1 բազա (binding՝ DB)։ Ամբողջ վիճակը մեկ JSON՝ սենյակի կոդով, տարբերակի հաշվիչով (optimistic concurrency, 409 կոնֆլիկտի դեպքում)։ Հաճախորդը հարցում է անում 4 վրկ-ը մեկ։

Մուտք՝ դեմո մակարդակի (գաղտնաբառի SHA-256 հեշը կոդի մեջ է)։ Իրական արտադրանքի համար անհրաժեշտ է սերվերային authentication։

User Guide

Shop–supplier collaboration platform · version 5 (prototype)

What is ArmTrade?

A platform where a shop and its supplier work without phone calls. The system tracks the store's stock and sales, suggests what to order and when, and keeps orders, invoices and debts visible to both sides in real time.

Quick start

RolePasswordSees
🏪 Shopnran2026Orders, sales, debts
🚚 Supplieraqua2026Orders, store stock, accounting

Open the app on two different devices and sign in with different roles — they connect automatically: an order placed on one device appears on the other within seconds. The "Demo mode" link shows both sides on one screen for presentations.

Top bar: 🌙/☀️ theme 🔗 connection 🔔 notifications EN/РУ/ՀԱՅ language ⏭ next day (demo)

Shop side

  • 📋 Today — what needs reordering today; the system learns each product's cycle. Supplier 📨 offers land here and are confirmed with one tap.
  • 🛒 Products — full catalog with prices and promos, search and filters.
  • 💵 Sales — record daily retail sales; stock decreases and the supplier sees it live.
  • 🧺 Basket — orders are split by supplier; pick a delivery day. A warning appears if an order would exceed the credit limit.
  • 📦 Orders — status tracker (New → Confirmed → Delivered), 💬 chat, ↩ returns.
  • 💳 Debts — debt per supplier, credit-limit gauge, payment.
  • 📈 Data — monthly spend, invoices (tap to print), payments, history, CSV export.

Supplier side

  • 📊 Dashboard — today at a glance, 🔮 7-day demand forecast, pending orders.
  • 📉 Stock — the store's live stock and sales velocity: days until each product runs out, 7-day sales chart, "📨 Suggest order" button.
  • 📥 Orders — 🗺 delivery plan grouped by day, confirm, ✂ partial delivery, chat.
  • 🏪 Shops — stock map of every store: green/yellow/red chips per product, 🚨 critical counters.
  • 🔔 Alerts — fires when a shop stops ordering or a cycle is overdue; "Remind" sends the shop a ready-made offer.
  • 🏷 Price list — start/stop −10% promos; shops see the new price instantly.
  • 📈 Data — revenue, receivables (💰 receive payment, 📄 reconciliation statement), invoices with days-overdue, CSV.

Shared features

  • Notifications — tap "Enable" on the banner and allow in the browser. Test via 🔔 → "Test notification". On iPhone, add the app to the Home Screen (Share → Add to Home Screen) for system notifications.
  • Device connection — automatic when signed in. Without login, use 🔗 to generate a room code and enter the same code on both devices.
  • ⏭ Day simulator — for demos: advances one day, stores "sell", new orders arrive.
  • Reset — Dashboard → "↺ Reset" clears the demo data.

Technical handoff (for developers)

Architecture: a single file armtrade/index.html (HTML+CSS+JS, no frameworks). Hosted on Cloudflare Pages with auto-deploy from GitHub: github.com/hrachyajavadyan/assay.

Sync: Cloudflare Pages Function functions/api/room/[code].js + a D1 database (binding DB). The whole state is one JSON blob per room code with a version counter (optimistic concurrency, 409 on conflict). Clients poll every 4 s.

Auth: demo-grade (SHA-256 password hashes embedded in the client). A production build needs server-side authentication.

Roadmap (v6): server-side accounts, real push notifications (app closed), granular (non-blob) sync, real multi-shop accounts.

Руководство

Платформа «магазин–поставщик» · версия 5 (прототип)

Что такое ArmTrade?

Платформа, где магазин и поставщик работают без звонков. Система следит за остатками и продажами магазина, сама подсказывает, что и когда заказать, а заказы, счета и долги видны обеим сторонам в реальном времени.

Откройте программу на двух устройствах и войдите под разными ролями — они соединятся автоматически: заказ с одного устройства появится на другом за несколько секунд. «Демо-режим» показывает обе стороны на одном экране — удобно для презентаций.

Верхняя панель: 🌙/☀️ тема 🔗 связь 🔔 уведомления EN/РУ/ՀԱՅ язык ⏭ следующий день (демо)

Сторона магазина

  • 📋 Сегодня — что пора заказать; система выучивает цикл каждого товара. Сюда же приходят 📨 предложения поставщика — подтверждаются одним нажатием.
  • 🛒 Товары — весь ассортимент с ценами и акциями, поиск и фильтры.
  • 💵 Продажи — записывайте дневные продажи; остаток уменьшается, поставщик видит это в прямом эфире.
  • 🧺 Корзина — заказ делится по поставщикам; выбирается день доставки. При превышении кредитного лимита — предупреждение.
  • 📦 Заказы — статус (Новый → Подтверждён → Доставлен), 💬 чат, ↩ возврат.
  • 💳 Долги — долг каждому поставщику, шкала лимита, оплата.
  • 📈 Данные — расходы по месяцам, счета (нажмите — печать), платежи, история, CSV.

Сторона поставщика

  • 📊 Панель — картина дня, 🔮 прогноз на 7 дней, ожидающие заказы.
  • 📉 Склад — остатки и скорость продаж магазина в прямом эфире: через сколько дней закончится каждый товар, график за 7 дней, кнопка «📨 Предложить заказ».
  • 📥 Заказы — 🗺 план доставок по дням, подтверждение, ✂ частичная доставка, чат.
  • 🏪 Магазины — карта остатков по всем магазинам: зелёные/жёлтые/красные чипы по каждому товару, 🚨 счётчик критичных.
  • 🔔 Сигналы — когда магазин перестал заказывать или цикл просрочен; «Напомнить» отправляет магазину готовое предложение.
  • 🏷 Прайс — включение/выключение акции −10%; магазины видят цену сразу.
  • 📈 Данные — выручка, дебиторка (💰 приём платежа, 📄 акт сверки), счета с днями просрочки, CSV.

Общее

  • Уведомления — нажмите «Включить» на баннере и разрешите в браузере. Проверка: 🔔 → «Тестовое уведомление». На iPhone для системных уведомлений добавьте программу на экран «Домой» (Поделиться → На экран «Домой»).
  • Связь устройств — автоматическая при входе. Без входа: кнопкой 🔗 создайте код комнаты и введите одинаковый код на двух устройствах.
  • ⏭ Симулятор дня — для демо: наступает следующий день, магазины «продают», приходят новые заказы.
  • Сброс — Панель → «↺ Сброс» очищает демо-данные.

Техническая справка (для разработчика)

Архитектура: один файл armtrade/index.html (HTML+CSS+JS, без фреймворков). Хостинг — Cloudflare Pages, автодеплой из GitHub: github.com/hrachyajavadyan/assay.

Синхронизация: Cloudflare Pages Function functions/api/room/[code].js + база D1 (binding DB). Всё состояние — один JSON на код комнаты со счётчиком версий (оптимистическая блокировка, 409 при конфликте). Клиенты опрашивают сервер каждые 4 с.

Авторизация: демо-уровня (SHA-256-хеши паролей в клиенте). Для продакшена нужна серверная аутентификация.

Дальше (v6): серверные аккаунты, настоящие push-уведомления (при закрытой программе), частичная (не цельным блоком) синхронизация, реальные аккаунты для многих магазинов.
